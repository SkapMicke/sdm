SIMONS DANSMEDIA WORKSPACE 1.0

Publicera hela mappen på en HTTPS-webbserver, exempelvis Vercel eller Netlify (statisk webbplats).
Öppna adressen i Chrome på Android och välj menyn > Lägg till på startskärmen / Installera app.

Funktioner: kalender med uppdrag, påminnelser, anteckningar, översikt, export/import av säkerhetskopia, offline-cache och PWA-installation.
Data lagras lokalt i webbläsaren. Exportera säkerhetskopior regelbundet. Ingen synkronisering mellan enheter.
Notiser fungerar endast när webbappen är aktiv och webbläsaren tillåter aviseringar. För garanterade bakgrundsnotiser krävs pushserver och prenumerationer.
PWA-installation/service worker fungerar via HTTPS eller localhost, inte genom att öppna index.html direkt som en fil.
